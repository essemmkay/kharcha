## Direction contract

THESIS: Your money rendered with the gravitas, craft, and security of currency
itself — the balance IS a banknote you own. Refuses the fintech default (floating
ink "black card" + neon accent + soft donut) and its opposite (bare spreadsheet).
Trust is shown through engraving craft, not chrome.

OWN-WORLD: Intaglio banknote. Committed bottle-green ink field owns the note/hero
and key chrome; warm fibrous banknote-paper ground for data; deep intaglio
vermilion for expense/cancellation, sepia for transfer/neutral, one sparing
foil-gold seal. Real generated guilloché (SVG rose curves), hairline engraving
rules, microprint strips. Type: Libre Caslon (engraved roman, masthead + hero
numerals) + Archivo tracked caps (denomination labels, column heads) + tabular
lining figures for ledger tables. Numerals are the hero, right-aligned, running
totals ruled.

STORY: Visitor sees their whole worth issued as a banknote (seal, serial, value),
scans the month's entries as ruled ledger lines, writes a new entry onto the next
counterfoil, and issues a statement. State is printed: synced = struck seal +
serial; deleted = VOID overprint, never removed (maps to soft-delete tombstones).

FIRST VIEWPORT: Dashboard. A bottle-green banknote hero fills the top: guilloché
behind a large engraved net-worth value under its "NET WORTH" denomination label,
with date-of-issue, a synthetic serial, corner value counters, a microprint
baseline, and a foil seal carrying sync state. Below on paper: IN/OUT/NET ruled
counters, an engraved month selector, spending-by-category as a ruled table with
intaglio-line bars, recent entries as ledger lines. Primary action "+ ENTER" sits
thumb-reachable.

FORM: The Engraving (banknote intaglio); user-pinned pick, candidate #1 of my
grounded list, over assigned #6 "The Register"; seed key 7d1655eb. Raised by
declined/competitive challengers: ruling-engine (crisp 1px rules + printed-mark
states), ticket-wallet (carbon figures, VOID-cancel state), exposure-record
(strict tonal ramp as the only grays), guide-map (committed color field owns
regions). Light-primary (a note is printed); deep-ink dark rendition for night.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
